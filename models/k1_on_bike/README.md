# K1 on the bike (seated)

The K1 sitting on a bike: both hands welded to the handlebar grips, pelvis resting on the
saddle by contact only, feet flat on the floor. It works on any bike in `models/` that has a
solved pose here. By default it sits on the real bike, [models/puky_bike](../puky_bike/README.md).

| File or code | What |
|---|---|
| `puky_bike.json` | Seated pose on the real bike (default); generated by `scripts/solve_seated_pose.py` |
| `yellow_bike.json` | Seated pose on the yellow bike (the earlier green one; `--bike yellow_bike`) |
| `src/k1bike/seat.py` | Hand-clip sites and welds, loading a bike's pose, `seat_contact()` (saddle force) |
| `src/k1bike/scene.py` | `k1_seated_bike_scene(bike_xml)`: K1 + bike + floor, with keyframe `seated` |

Each pose file holds the trunk pose relative to the bike frame, the joint angles, and the fit
(`fit`: pelvis-saddle distance, clip-to-grip and foot-to-floor errors, trunk lean).

View it (holds the pose with the k1_walk PD gains):

```bash
uv run python scripts/view_model.py k1_seated                          # Linux host, real bike
uv run python scripts/view_model.py k1_seated --model yellow_bike    # Linux host, yellow bike
uv run mjpython scripts/view_model.py k1_seated                        # macOS host, real bike
uv run mjpython scripts/view_model.py k1_seated --model yellow_bike  # macOS host, yellow bike
```

Solve or re-solve a bike's pose after changing that bike or the clip geometry (Linux and
macOS). It refuses to write a pose whose fit fails and says which target failed:

```bash
uv run --group sim python scripts/solve_seated_pose.py                         # real bike
uv run --group sim python scripts/solve_seated_pose.py --bike yellow_bike    # another bike
```

To seat the K1 on a new bike: give the bike the standard part names (`frame`, `fork`,
`saddle`, `seat`, `left_grip`, `right_grip`, `steer`, `root`), add it to `BIKES` in
`src/k1bike/paths.py`, and solve its pose. `tests/test_seat.py` then runs every seat test on
it too.

How the welds, the contact-only seat, the assumed clip frame and the collision rules work,
and the current fit on each bike: [docs/bike-dimensions.md, Seated K1](../../docs/bike-dimensions.md#seated-k1).
The clip frame is assumed until the [hand clips](../hand_clips/README.md) are attached; then
the clips touch the bar through their own geoms and the forearm-fork contact exclusion goes.
