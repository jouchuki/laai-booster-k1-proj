# K1 on the bike (seated)

The K1 sitting on [models/bike](../bike/README.md): both hands welded to the handlebar grips,
pelvis resting on the saddle by contact only, feet flat on the floor.

| File or code | What |
|---|---|
| `seated_pose.json` | Solved joint angles and trunk pose; generated by `scripts/solve_seated_pose.py` |
| `src/k1bike/seat.py` | Hand-clip sites and welds, the seated keyframe, `seat_contact()` (saddle force) |
| `src/k1bike/scene.py` | `k1_seated_bike_scene()`: K1 + bike + floor, with keyframe `seated` |

View it (holds the pose with the k1_walk PD gains):

```bash
uv run python scripts/view_model.py k1_seated      # Linux host
uv run mjpython scripts/view_model.py k1_seated    # macOS host
```

Re-solve the pose after changing the bike or the clip geometry (Linux and macOS):

```bash
uv run --group sim python scripts/solve_seated_pose.py
```

How the welds, the contact-only seat, the assumed clip frame and the collision rules work,
and the current fit: [docs/bike-dimensions.md, Seated K1](../../docs/bike-dimensions.md#seated-k1).
The clip frame is assumed until Vlad's hand model is attached; then the hands touch the bar
through their own geoms and the forearm-fork contact exclusion goes.
