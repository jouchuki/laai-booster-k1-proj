# Robot credentials (template)

Copy this file to `credentials.md` in the same folder and fill in the values.
`credentials.md` is gitignored; ask a teammate for the real values.

## Booster K1

| What            | Value                     |
|-----------------|---------------------------|
| SSH user        | `<user>`                  |
| SSH password    | `<password>`              |
| Robot IP        | `<ip>`                    |
| Hostname        | `<hostname>`              |
| Login command   | `ssh <user>@<ip>`         |

## Network

| What            | Value                     |
|-----------------|---------------------------|
| Wi-Fi network   | `<network name>`          |
| Robot Wi-Fi connection name | `<nmcli connection name>` |
| Booster app     | `<app name>`              |
